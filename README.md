# Börsitark

Investeerimine selges eesti keeles: teemad kolmel tasemel, sõnastik, kalkulaatorid, tasude võrdlus ja harjutusportfell.

Kogu sait on üks fail: `index.html`. Serverit ega andmebaasi pole vaja.

## Kohalikult avamine

Ava `index.html` topeltklõpsuga brauseris.

## Avaldamine GitHub Pagesis

1. Loo GitHubis uus avalik hoidla, nt `borsitark`.
2. Lae `index.html` hoidla juurkausta.
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, kaust `/ (root)` → Save.
4. Mõne minuti pärast on sait aadressil `https://<kasutajanimi>.github.io/borsitark/`.

## Teada olevad piirangud

- Foorum ja harjutusportfell salvestuvad ainult kasutaja enda brauserisse (localStorage).
- AI-abiline vastab saidi enda teemade põhjal, päris AI-ühendust pole.
- Tasude võrdluse hinnad on kontrollitud 23.11.2026. Uuenda need, kui pankade hinnakirjad muutuvad.
- Maksu- ja pensionitekstid tuleb enne laiemat avaldamist lasta asjatundjal üle vaadata.
